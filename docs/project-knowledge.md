# Проектная фактура для агентов

## Источник правды

Ручная карта тем не нужна. Источник правды уже выгружен из кода сайта в папку:

`/Users/romanrazumovich/lexis_voice/landing/handoff-konveyer/fakty/`

Файлы пересобираются командой из проекта сайта:

```bash
pnpm export:konveyer
```

## Что лежит в `fakty/`

- `temy.json` — 104 готовых брифа: slug, URL, тип материала, вопрос, кластер, спрос, волна.
- `produkt.json` — продуктовые факты Lexis Voice: масштабирование, движки, данные, интеграции и статусы возможностей.
- `keysy.json` — кейсы и метрики внедрений; цифры, которых здесь нет, нельзя придумывать.
- `konkurenty.json` — публично проверяемые профили других продуктов с датой снимка.
- `terminy.json` — определения терминов, которые нельзя переписывать.
- `glossariy.json` — страницы глоссария; если термин уже определен, второй раз его не определяем.
- `vnutrennie-ssylki.json` — полный список внутренних ссылок, которые можно ставить в материале.

## Правила использования

- Факты о Lexis Voice, продукте, кейсах, масштабе, интеграциях и метриках берутся только из `produkt.json` и `keysy.json`.
- Факты о других продуктах берутся только из `konkurenty.json` или с официального сайта самого продукта с датой снимка.
- Поисковик ищет внешний мир: методики, нормы, законы, новости, рыночную практику. Он не ищет факты о Lexis Voice.
- Писатель использует только внутренние ссылки из `vnutrennie-ssylki.json`.
- Определения терминов из `terminy.json` должны совпадать слово в слово.

## Подключение в сервисе

Путь задается переменной окружения:

```bash
HANDOFF_KONVEYER_DIR=/Users/romanrazumovich/lexis_voice/landing/handoff-konveyer
```

Если переменная задана, `ProjectKnowledge` загружает `fakty/*.json`, а реальный поисковик получает эти данные в контекст. Команда Telegram-бота `/topics` показывает очередь тем из `temy.json`.

## Что это меняет

Агенты больше не должны угадывать темы, продуктовые обещания, кейсы, конкурентов и внутренние ссылки. Оркестратор берет тему из `temy.json`, прикладывает релевантную фактуру, а поисковик добавляет только внешние проверяемые факты.
