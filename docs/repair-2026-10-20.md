# Восстановление 20–21 октября 2026

Причины остановки:

- Старый systemd timer с 31 августа вызывает отсутствующий run-daily.js.
- Cron в 05:00 UTC запускает актуальный run-daily-topics-local.js, но старый gpt-5.5 возвращал пустые ответы/400. Необработанная ошибка оставляла первую тему running и останавливала очередь.
- Многие статьи достигли лимита 20 редакторских ревизий. Этот лимит и правила качества сохранены.
- Последняя успешная запись по старым журналам — A-0105, 4 сентября. Из 60 файлов гайдов сайт видел 31: 29 файлов содержали неподдерживаемые текущим renderer блоки example/expert/takeaways.

Изменения:

- Модель GPT-5.6 Terra; доступность и веб-поиск проверены реальными запросами провайдеру.
- Некорректный JSON получает одну попытку исправления синтаксиса той же моделью; результат всё равно проходит содержательные проверки.
- Timeout действует и на чтение тела ответа; пустой ответ повторяется ограниченное число раз.
- Ошибка API сохраняется в очереди и daily-report.json, процесс завершается ненулевым кодом. Каждая тема обрабатывается не более одного раза за дневной запуск.
- Публикация проверяет фактическую доступность публичной страницы.
- Добавлен режим совместимости с установленным renderer и проверяемое восстановление старых файлов без изменения текста и дат.
- Убрано удаление отрицательных частей предложений из автоочистки: regex мог менять смысл и оставлять обрывки. Правила качества продолжают проверять стиль; исправление формулировок остаётся за писателем.
- Для legacy-режима отключено внедрение шаблонных v2-примеров и комментариев эксперта; вступление больше не обрезается посреди предложения.
- Писателю явно передан лимит длины CTA, который раньше был только в валидаторе.
- Зависимости закреплены pnpm-lock.yaml; инструкции и cron хранятся в репозитории.
